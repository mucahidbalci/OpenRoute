# Android client — planned

The Android app has not been implemented in this MVP scaffold.

Planned initial build: Kotlin + Jetpack Compose, with explicit on-screen connection tests and no background VPN or traffic routing. Each test destination and the data sent to it will be documented. If an opt-in VPN-based module is considered in the future, it must use Android's `VpnService` permission flow, clearly disclose routing behavior, and undergo security review.

No APK is published yet. Do not install APKs from unofficial mirrors.
